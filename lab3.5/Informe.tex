\subsection{Actividad 5.1: Control remoto de servomotor mediante Sockets}
\textit{
    Enunciado: Implemente una arquitectura de comunicación Socket TCP utilizando la librería nativa processing.net de Processing para permitir el control de dispositivos IoT a través de la red:
    \begin{itemize}
        \item Construya un Socket Server en el equipo que posee el hardware (ATmega2560) y un Socket Client en un equipo remoto para controlar la posición de un servomotor por internet. (2 puntos)
    \end{itemize}
}

\subsection{Actividad 5.2: Integración de Joystick}
\textit{
    Enunciado: Integre un Joystick físico al sistema para el control dinámico de los actuadores mediante una arquitectura unificada:
    \begin{itemize}
        \item Realice la conexión del Joystick a la placa: terminales VRX al pin analógico A0, VRY al pin A1 y el pulsador SW al pin digital 2. (1 punto)
        \item Desarrolle un sistema Híbrido (Cliente-Servidor unificado) donde el código sea capaz de leer el hardware localmente y, simultáneamente, transmitir la telemetría a una interfaz simplificada. (2 puntos)
        \item Implemente una lógica de mapeo del movimiento en el eje X y eje Y para controlar el rango de 0° a 90° del servo. (2 puntos)
        \item Diseñe una interfaz de usuario simplificada que muestre en tiempo real el ángulo actual del servomotor y los ángulos de inclinación detectados en los ejes X e Y del joystick. (3 puntos)
    \end{itemize}
}
